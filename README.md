# Katha Studio

Professional screenwriting for Indian film and OTT writers — with Tamil, Telugu,
Hindi, Malayalam and Kannada built in.

**Use it in your browser:** https://adijustadi01.github.io/katha-studio/

_(Full installation and release instructions are added as the desktop app lands.)_

## Develop

```bash
npm install
npm run dev      # http://localhost:5173/katha-studio/
npm test         # unit tests (formatting, pagination, import/export, transliteration)
npm run build    # production web build in dist/
```
